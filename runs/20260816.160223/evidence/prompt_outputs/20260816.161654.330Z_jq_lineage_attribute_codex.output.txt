output.

</requirement>
<requirement name="core-filter-composition" stories="eval-core">
Filters can be combined in various ways - you can pipe the output of
one filter into another filter, or collect the output of a filter
into an array.
</requirement>
<requirement name="cartesian-filter-evaluation" stories="eval-cartesian">
If the one on the left produces multiple results, the one on the right
will be run for each of those results.
</requirement>
<requirement name="json-values" stories="values-model">
jq supports the same set of datatypes as JSON - numbers,
strings, booleans, arrays, objects (which in JSON-speak are
hashes with only string keys), and "null".
</requirement>
<requirement name="arithmetic-operators" stories="values-arithmetic">

produces a value other than false or null, but act the same as
`C` otherwise.
</requirement>

</requirement>

</requirement>
