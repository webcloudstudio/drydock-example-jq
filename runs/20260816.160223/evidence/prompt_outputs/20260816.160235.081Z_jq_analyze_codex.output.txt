### Test and Acceptance Strategy

Implementation stories use focused corpus selections and unit tests for their owned semantics. No development story runs the complete suite. `VERIFY-002` is the single terminal story that runs `sh sources/full_test.sh` with `Suite: full` and asserts only successful completion. The same command is the project Sea Trial proof.

### Sequencing and Dependencies

Stage all supplied assets before verification. Implement the lexer before the parser, the parser before evaluator normalization, and the generator core before control flow, functions, paths, assignments, and builtins. Complete the executable contract before harness execution. The final full-suite story depends on every implementation story and preserves the supplied harness and exclusions.

### Source Conflicts and Gaps

No conflicting product definitions were found. Module-loader cases are explicitly excluded by `sources/exclusions.txt`; module grammar rejection remains in scope. The sources prescribe Python standard-library implementation and prohibit third-party jq implementations, system jq delegation, package installation, and network access.

# COMPASS: jq

## Compass

Build a self-contained jq 1.8.2 language interpreter for developers and automated tooling. The product is a root-level executable named `jq` that evaluates jq filters against JSON values from standard input and emits the resulting stream as compact JSON lines.

## Constraints

- Implement in Python using only the standard library.
- Support the exercised `./jq -c '<program>'` interface.
- Use no package installation, network access, or external runtime dependency.
- Stage and preserve the supplied corpus and harness assets.
- Keep module-loader cases excluded only as declared in `sources/exclusions.txt`.

## Guardrails

- Never shell out to a system jq binary.
- Never use a third-party jq implementation or binding.
- Never modify the supplied scoring script, corpus, exclusions, or conformance runner.
- Preserve generator ordering, backtracking, compile/runtime exit distinctions, and outputs emitted before runtime errors.
