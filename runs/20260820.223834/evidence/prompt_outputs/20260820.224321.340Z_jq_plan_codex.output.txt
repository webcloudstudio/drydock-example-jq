# FEATURE: Front End Diagnostics

| Field       | Value |
|-------------|-------|
| Version     | 20260820 V1 |
| Description | Reject invalid jq programs at compile time with the required exit status. |
| Depends On  | FEATURE-Frontend-Parser.md |
| Provides    | compile exit status 3 |
| Consumes    | jq AST and filter grammar |

## Questions

- None.

## Scope

Compilation failures are distinct from runtime failures. Invalid syntax, literals, unresolved labels, invalid object keys, and invalid module grammar must be rejected without filesystem access. Diagnostics are written to standard error and are not part of the compatibility contract.

## Programmatic Acceptance

=== AC diagnostics-conformance ===
Intent: The selected compile-diagnostic corpus slice executes and passes.
Suite: scoped

import json
import os
import subprocess
import sys

selector = r"(module|include|%::|break|Invalid escape)"
result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select", selector, "--json"],
    capture_output=True,
    text=True,
    env={**os.environ, "JQ": f"{os.getcwd()}/jq"},
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
report = json.loads(result.stdout)
summary = report["summary"]
assert sum(summary.values()) > 0
assert summary["fail"] == 0 and summary["error"] == 0
assert result.returncode == 0
=== END AC diagnostics-conformance ===

=== AC diagnostics-exit-code ===
Intent: A syntactically invalid program returns the compile-error exit status.

import subprocess

program = "{"
result = subprocess.run(
    ["./jq", "-c", program],
    input="null\n",
    capture_output=True,
    text=True,
)
assert result.returncode == 3
=== END AC diagnostics-exit-code ===

=== AC diagnostics-runtime-distinction ===
Intent: A syntactically valid program is not classified as a compile failure.

import subprocess

program = "error"
result = subprocess.run(
    ["./jq", "-c", program],
    input="null\n",
    capture_output=True,
    text=True,
)
assert result.returncode != 3
=== END AC diagnostics-runtime-distinction ===

## User Acceptance

- None.

## Guardrails

- Do not read module files while rejecting invalid module grammar.
- Do not shell out to a system jq executable.
- Do not reproduce or compare diagnostic wording.

# FEATURE: Core Generators

| Field       | Value |
|-------------|-------|
| Version     | 20260820 V1 |
| Description | Evaluate jq filters as ordered zero-, one-, or many-value streams. |
| Depends On  | FEATURE-Frontend-Diagnostics.md |
| Provides    | ordered generator evaluation, pipeline composition, backtracking |
| Consumes    | jq AST and filter grammar |

## Questions

- None.

## Scope

The evaluator treats every filter as a generator over an input value. Identity, literals, comma, pipe, empty, iteration, collection, and downstream composition preserve ordering, multiplicity, cartesian behavior, and backtracking.

## Programmatic Acceptance

=== AC generators-conformance ===
Intent: The selected generator corpus slice executes and passes.
Suite: scoped

import os
import subprocess
import sys

selector = r"(\.|\.\[\]|,|\||empty)"

    [sys.executable, "sources/run_conformance.py", "--select", selector, "--json"],
    capture_output=True,
    text=True,
    env={**os.environ, "JQ": f"{os.getcwd()}/jq"},
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
report = json.loads(result.stdout)
summary = report["summary"]
assert sum(summary.values()) > 0
assert summary["fail"] == 0 and summary["error"] == 0
assert result.returncode == 0
=== END AC generators-conformance ===

=== AC generators-order ===
Intent: A generator preserves the supplied input ordering and multiplicity.

import json
import subprocess

program = "[.[]]"
payload = "[3,1,3]\n"
result = subprocess.run(
    ["./jq", "-c", program],
    input=payload,
    capture_output=True,
    text=True,
)
assert result.returncode == 0

expected = json.loads(payload)
assert actual == expected
=== END AC generators-order ===

=== AC generators-pipeline ===
Intent: A downstream filter runs once for each upstream generator output.

import json
import subprocess

program = "[.[] | . * 2]"
payload = "[1,2,3]\n"
result = subprocess.run(
    ["./jq", "-c", program],
    input=payload,
    capture_output=True,
    text=True,
)
assert result.returncode == 0
actual = json.loads(result.stdout)
expected = [value * 2 for value in json.loads(payload)]
assert actual == expected
=== END AC generators-pipeline ===

## User Acceptance

- None.

## Guardrails

- Preserve generator ordering, multiplicity, and partial backtracking.
- Do not collapse streams into single values during evaluation.

# FEATURE: Core Errors

| Field       | Value |
|-------------|-------|
| Version     | 20260820 V1 |
| Description | Implement jq runtime errors, suppression, alternatives, and partial output. |
| Depends On  | FEATURE-Core-Expressions.md |
| Provides    | runtime exit status 5, try/catch, optional filters, empty, defined-or |
| Consumes    | literals, indexing, construction, and core operators |

## Questions

- None.

## Scope

Runtime failures are distinct from compilation failures and return exit status 5. `try`, `catch`, `?`, `empty`, and `//` preserve jq stream semantics. Values emitted before an uncaught runtime error remain on standard output.

## Programmatic Acceptance

    [sys.executable, "sources/run_conformance.py", "--select", selector, "--json"],
    capture_output=True,
    text=True,
    env={**os.environ, "JQ": f"{os.getcwd()}/jq"},
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
report = json.loads(result.stdout)
summary = report["summary"]
assert sum(summary.values()) > 0
assert summary["fail"] == 0 and summary["error"] == 0
assert result.returncode == 0
=== END AC errors-conformance ===

=== AC errors-runtime-status ===
Intent: An uncaught runtime error returns the runtime-error status.

import subprocess

result = subprocess.run(
    ["./jq", "-c", "error"],
    input="null\n",
    capture_output=True,
    text=True,
)
assert result.returncode == 5
=== END AC errors-runtime-status ===

=== AC errors-partial-output ===
Intent: Values emitted before a runtime error remain available.

import json
import subprocess

result = subprocess.run(
    ["./jq", "-c", "1, error"],
    input="null\n",
    capture_output=True,
    text=True,
)
assert result.returncode == 5
actual = [json.loads(line) for line in result.stdout.splitlines()]
expected = [1]
assert actual == expected
=== END AC errors-partial-output ===

## User Acceptance

- None.

## Guardrails

- Preserve output produced before runtime failure.
- `try` and optional evaluation must suppress only the relevant failure.
- Never convert runtime failures into compile exit status 3.
