# FEATURE: Control Bindings

| Field       | Value |
|-------------|-------|
| Version     | 20260820 V1 |
| Description | Defines lexical variable bindings, destructuring patterns, and binding alternatives. |
| Depends On  | FEATURE-Control-Reductions.md |
| Provides    | `as` bindings, lexical variables, array and object patterns, `?//` alternatives |
| Consumes    | generator evaluation, filter scope, pattern matching |

## Questions

- None.

## Purpose

Implement jq's lexical binding model. Bindings capture values produced by filters while the continuation receives the original input. Scope is lexical and immutable; nested bindings may shadow outer names.

Support:

- Scalar bindings with `as $name`.
- Array and object destructuring patterns.
- Missing array members and object keys binding to `null`.
- Lexical scope and shadowing.
- Destructuring alternatives using `?//`.
- Generator-valued binding expressions and fallback behavior.
- Error propagation from the final alternative.

## Programmatic Acceptance

=== AC control-bindings-conformance ===
Intent: The scoped authoritative corpus cases covering bindings, patterns, lexical scope, and destructuring alternatives execute and pass.
Suite: scoped
Requires: executable=python3; scope=test

import json
import os
import subprocess
import sys

selector = r"( as \$|\?//|\[\$|\{\$)"
result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select", selector, "--json"],
    capture_output=True,
    text=True,
    env={**os.environ, "JQ": f"{os.getcwd()}/jq"},
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
report = json.loads(result.stdout)
summary = report["summary"]
assert sum(summary.values()) > 0
assert summary["fail"] == 0 and summary["error"] == 0
assert result.returncode == 0
=== END AC control-bindings-conformance ===

## User Acceptance

- None.

## Guardrails

- Variable bindings must not leak outside their lexical scope.
- Destructuring alternatives must preserve generator ordering and final-error behavior.
- No third-party runtime dependency may be introduced.
