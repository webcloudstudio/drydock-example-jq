name: jq display_name: drydock jq Uat Case short_description: Drydock uat - jq is the flagship kit and the largest test bed here. The kit consists of the jq 1.8.2 manual rendered to text, the upstream grammar and builtin definitions, and the upstream conformance corpus of several hundred cases taken byte for byte from the jq repository, which PROVENANCE.md records with a SHA-256 for every imported file. It proves that Drydock builds a real language implementation, not a parser or a CRUD application: jq is a small language with a large semantic core, almost every filter is a generator producing a stream of values, and an implementation that treats a filter as a function returning one value passes the early cases and then stalls permanently. The evaluation model has to be decided in design, before any code is written, which is exactly what the specification-driven pipeline is for. It also proves that skips are auditable rather than silent: the corpus is never edited, and the handful of cases the kit physically cannot run are named with their reasons in exclusions.txt, which is hash-verified with the rest of the scoring assets so a tampered exam is reported instead of honored. TECHNOLOGY_STACK.md specifies Python with no third-party runtime dependency, but the harness knows the implementation only through an executable named jq, so any language builds it once you supply its Rigging file (copy the python.md format). Run with drydock uat jq.
