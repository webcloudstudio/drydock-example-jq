## Questions

- None.

## System Boundary

The executable `jq` accepts `-c PROGRAM`, reads JSON values from standard input, evaluates the program as an ordered jq generator, and writes compact JSON values to standard output, one per line.

## Module Boundaries

- `cli`: argument parsing, JSON input decoding, output serialization, diagnostics, and exit codes.
- `lexer`: jq tokenization, comments, literals, strings, interpolation, formats, and delimiters.
- `parser`: precedence-aware parsing into an AST and compile-time validation.
- `runtime`: generator evaluation, lexical environments, control flow, errors, and labels.
- `values`: native Python JSON-compatible values, numeric handling, structural equality, and ordering.
- `paths`: path discovery, reads, immutable updates, deletion, and assignment.
- `builtins`: jq-defined and Python-implemented builtin filters.
- `sources`: read-only conformance and normative assets.

Evaluation is stream-based: every filter receives one input and yields zero or more outputs. Pipes evaluate downstream filters once per upstream output; commas preserve left-to-right ordering; runtime errors retain output already emitted.

## Technology Stack

- Python 3.11 or newer, standard library only.
- POSIX `sh` for the supplied verification entry point.

## Constraints and Interfaces

The implementation must not invoke a system jq, import a third-party jq implementation, access the network, install packages, or modify files under `sources/`. Compile failures exit `3`; runtime failures exit `5`; successful completion exits `0`.

## Questions

- None.

## Interface

The executable is invoked as `./jq -c PROGRAM`. It reads one or more JSON values from standard input and emits every generated result as one compact JSON value per line. Diagnostics go to standard error.

A valid program that completes exits `0`. A program that fails compilation exits `3`. A program that raises during evaluation exits `5`, while retaining values emitted before the error.

## Programmatic Acceptance

=== AC cli-valid-stream ===
Intent: The executable accepts -c, processes multiple JSON inputs, and emits one compact result per input.

import json
import os
import subprocess

program = "."
values = [{"a": 1}, [2, 3]]
payload = "".join(json.dumps(value) + "\n" for value in values)
result = subprocess.run(
    ["./jq", "-c", program],
    input=payload,
    capture_output=True,
    text=True,
    env={**os.environ},
)
assert result.returncode == 0
actual = [json.loads(line) for line in result.stdout.splitlines()]
assert actual == values
=== END AC cli-valid-stream ===
