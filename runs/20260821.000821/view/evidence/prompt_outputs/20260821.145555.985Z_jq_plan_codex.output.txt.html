## Scope

Destructuring binds array positions and object members to lexical variables. Missing array positions and object members bind to `null`. Nested patterns compose across arrays and objects.

# FEATURE: jq Generator Evaluation Core

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Evaluate every jq filter as an ordered zero-or-more value stream. |
| Depends On  | ARCHITECTURE.md, FEATURE-Parser.md |
| Provides    | ordered filter streams, backtracking, multiplicity, empty |
| Consumes    | parser, AST |

## Questions

- None.

## Scope

The evaluator represents each filter as a generator of zero or more values. Comma concatenates streams in source order; pipe evaluates its right side once for every left-side output; expressions with multiple outputs preserve cartesian products. `empty` produces no values and backtracking resumes the preceding generator.

Runtime errors may occur after earlier values have been emitted; those values remain observable.
