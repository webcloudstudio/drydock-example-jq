# FEATURE: Path Assignment Operators

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Defines jq plain, update, arithmetic, and defined-or assignment semantics. |
| Depends On  | FEATURE-PATHS-002.md |
| Provides    | jq assignment operators: =, |=, +=, -=, *=, /=, %=, //= |
| Consumes    | Immutable path mutation and deletion |

## Questions

- None.

## Purpose

Assignment evaluates left-hand paths against the original input and produces immutable updated values. Plain assignment applies every right-hand-side result; update and arithmetic assignments use the first update result, and `empty` deletes the selected path.

## Behavior

- Support multi-path left-hand expressions and generator right-hand expressions.
- Implement `=`, `|=`, `+=`, `-=`, `*=`, `/=`, `%=`, and `//=`.
- Preserve jq path ordering and output multiplicity.
- Delete paths when update assignment produces `empty`.
- Never mutate the original value visible to sibling expressions.
