# FEATURE: Assignment Operators

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Implements immutable jq assignment and update-assignment operators. |
| Depends On  | FEATURE-Path-Mutation.md |
| Provides    | =, |=, +=, -=, *=, /=, %=, //= |
| Consumes    | path, getpath, setpath, delpaths |

## Questions

- None.

## Behavior

Assignment evaluates left-hand-side path expressions against the original input and produces immutable replacement values. Plain assignment applies every right-hand-side output, while update assignment uses the selected path value and its first replacement output. Empty update results delete the selected path. Multiple paths, nested creation, array growth, slices, arithmetic updates, defined-or updates, and preservation of the original input snapshot are supported.

# FEATURE: Reductions and Bounded Iteration

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Implements jq reductions, extraction, and bounded generator iteration. |
| Depends On  | FEATURE-Assignments.md, FEATURE-Destructuring.md |
| Provides    | reduce, foreach, limit, skip, first, last, nth |
| Consumes    | ordered filter streams, destructuring, assignment |

## Questions

- None.

## Behavior

`reduce` folds every output of a generator into an accumulator. `foreach` exposes intermediate accumulator values through an optional extraction filter. `limit` and `skip` operate on generator output counts, while `first`, `last`, and `nth` select values without changing ordering or evaluating unnecessary output. Accumulator bindings support array and object destructuring and label-aware early termination.

# FEATURE: Recursive Generator Control

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Implements jq recursive generator control functions. |
| Depends On  | FEATURE-Reductions.md, FEATURE-Control-and-Errors.md |
| Provides    | while, until, repeat, recurse |
| Consumes    | generator evaluator, conditional control flow |

## Questions

- None.

## Behavior

`while` emits each state while its condition remains true and recursively applies its update. `until` repeatedly applies its next filter until its condition becomes true. `repeat` recursively emits results until an error terminates the stream. `recurse` emits the current value and recursively generated descendants, including conditional and multi-output recursion, while preserving depth-first ordering and termination behavior.

## Questions

- None.

## Behavior

`any` and `all` evaluate generator predicates with jq truthiness and short-circuiting. `isempty` detects whether a generator produces no values. `range` supports one, two, and three argument forms with positive and negative steps. `combinations` produces Cartesian combinations, `transpose` pads jagged rows with null, and `in` and `inside` implement membership and containment inversion while preserving generator argument evaluation.
