# FEATURE: Core Filters

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Defines jq's fundamental filters, constructors, indexing, iteration, slices, and recursive descent. |
| Depends On  | FEATURE-Generator-Core.md |
| Provides    | identity, literals, arrays, objects, field access, indexing, iteration, slices, recursive descent |
| Consumes    | ordered filter streams, backtracking, empty |

## Questions

- None.

## Intent

This feature implements the core jq expressions that operate on the generator evaluator. Filters preserve jq's ordered stream semantics while constructing and accessing JSON values.

## Behaviors

- Identity and literal filters emit one value.
- Arrays collect all values generated by their body.
- Objects evaluate fields against the same input and preserve generator multiplicity.
- Field access, dynamic indexing, iteration, and slices support arrays, objects, and strings.
- Optional access suppresses indexing and iteration errors.
- Recursive descent emits the input and all descendant values.
- Empty emits no values.

# FEATURE: Operators

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Defines jq arithmetic, comparison, ordering, and boolean operator semantics. |
| Depends On  | FEATURE-Generator-Core.md, FEATURE-Core-Filters.md |
| Provides    | arithmetic operators, comparisons, and, or, not, jq ordering |
| Consumes    | ordered filter streams, JSON values, generator cartesian evaluation |

## Questions

- None.

## Intent

Operators evaluate their operands as jq filters against the same input, combine generator outputs with jq's type-directed semantics, and produce ordered results.

## Behaviors

- Arithmetic supports numbers and jq's array, string, object, and null rules.
- Multiplication recursively merges objects and supports string repetition.
- Division and modulo support numeric and string forms and reject zero divisors.
- Equality and ordering are structural, type-aware, and key-order independent.
- Operator operands preserve cartesian generator evaluation.
- `and`, `or`, and `not` use jq truthiness: only `false` and `null` are false.
- Numeric predicates and special floating-point values follow the supplied jq behavior.

# FEATURE: Control and Errors

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Defines jq conditionals, error handling, defaults, labels, breaks, and runtime failure behavior. |
| Depends On  | FEATURE-Generator-Core.md, FEATURE-Core-Filters.md, FEATURE-Operators.md |
| Provides    | if, elif, else, try, catch, ?, //, labels, breaks, runtime errors |
| Consumes    | ordered filter streams, operators, generator backtracking |

## Questions

- None.

## Intent

Control expressions route generator streams through conditional branches, recoverable errors, defaults, and lexical control boundaries while preserving partial output.

## Behaviors

- `if`, `elif`, and `else` evaluate branches per condition result.
- `try` and `catch` recover errors and pass the error value to the handler.
- `?` suppresses errors as `empty`.
- `//` emits non-null and non-false left results or evaluates its fallback.
- Labels and breaks terminate the nearest visible labeled computation.
- Uncaught runtime errors return exit code 5.
- Values emitted before an uncaught runtime error remain on stdout.

# FEATURE: Path Access

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Defines jq path discovery, path expressions, descendant paths, and path-based reads. |
| Depends On  | FEATURE-Generator-Core.md, FEATURE-Core-Filters.md, FEATURE-Control-and-Errors.md |
| Provides    | path, paths, getpath, path expressions |
| Consumes    | generator evaluator, field access, indexing, iteration |

## Questions

- None.

## Intent

Path access exposes jq's immutable JSON tree locations as arrays of string keys and numeric indices. Exact paths are reported even when values are absent; pattern paths enumerate existing matches.

## Behaviors

- `path` returns exact and pattern path arrays in generator order.
- `paths` emits non-root paths to descendants, optionally filtered by a node predicate.
- `getpath` reads values at supplied paths and returns null for missing values where jq specifies.
- Path expressions support nested fields, indices, slices, and iteration.
- Invalid path expressions raise runtime errors.
- Path discovery does not mutate the input.

=== AC path-access-basic-contract ===
Intent: The executable returns a path array for an exact path and reads that path back from the same input.

import json
import subprocess

source = '{"a":{"b":7}}\n'
path_result = subprocess.run(
    ["./jq", "-c", "path(.a.b)"],
    input=source,
    capture_output=True,
    text=True,
)
read_result = subprocess.run(
    ["./jq", "-c", 'getpath(["a","b"])'],
    input=source,
    capture_output=True,
    text=True,
)
assert path_result.returncode == 0
assert read_result.returncode == 0
assert json.loads(path_result.stdout) == ["a", "b"]

=== END AC path-access-basic-contract ===

## User Acceptance

- None.

## Guardrails

- Path arrays contain only string object keys and numeric array indices.
- Path queries must not modify source values.
- Invalid path errors must remain runtime errors, not compile errors.

# FEATURE: Path Mutation

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Defines immutable jq path updates, nested creation, replacement, and deletion. |
| Depends On  | FEATURE-Path-Access.md |
| Provides    | setpath, delpaths, del, immutable nested updates and deletion |
| Consumes    | path, getpath, generator evaluator |

## Questions

- None.

## Intent

Path mutation derives new JSON values from existing values without in-place mutation. It supports creation of missing containers, replacement at nested paths, deletion, slices, and invalid-path handling.

## Behaviors

- `setpath` creates or replaces nested object and array locations.
- `delpaths` removes multiple paths and preserves unaffected values.
- `del` converts path expressions into deletions.
- Array updates grow arrays with nulls where required.
- Negative indices follow jq rules, including documented errors.
- Updates are immutable and preserve the original value for later expressions.
- Excessively deep paths raise runtime errors.

=== AC path-mutation-round-trip ===
Intent: A setpath update is observable through a separate getpath invocation and leaves unrelated state intact.

import json
import subprocess

source = '{"keep":1}\n'
updated = subprocess.run(
    ["./jq", "-c", 'setpath(["nested","value"]; 2)'],
    input=source,
    capture_output=True,
    text=True,
)
read_back = subprocess.run(
    ["./jq", "-c", 'getpath(["nested","value"])'],
    input=updated.stdout,
    capture_output=True,
    text=True,
)
assert updated.returncode == 0
assert read_back.returncode == 0
assert json.loads(updated.stdout)["keep"] == 1
assert json.loads(read_back.stdout) == 2
=== END AC path-mutation-round-trip ===
