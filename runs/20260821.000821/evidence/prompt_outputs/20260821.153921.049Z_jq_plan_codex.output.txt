# FEATURE: Frontend Functions and Scope

Phase: 3

## Programmatic Acceptance

=== AC frontend-004-conformance ===
Intent: User-defined functions execute with lexical scope.
Suite: scoped

import os
import subprocess

result = subprocess.run(
    ["./jq", "-c", "def f: . + 1; f"],
    input="1\n",
    capture_output=True,
    text=True,
    env={**os.environ},
)
assert result.returncode == 0
assert result.stdout.strip() == "2"
