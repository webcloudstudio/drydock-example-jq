# FEATURE: Basic jq Filters and Constructors

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Implements jq's core filters, constructors, indexing, iteration, slices, and recursive descent. |
| Depends On  | ARCHITECTURE.md, FEATURE-CORE-001.md |
| Provides    | Identity, literals, comma, pipe, arrays, objects, field access, indexing, iteration, slices, recursive descent, empty |
| Consumes    | Stream evaluator |

## Questions

- None.

## Intent

This capability adds the fundamental jq expression forms on top of the stream evaluator. It preserves generator ordering while constructing and inspecting JSON arrays and objects.

## Behavior

- Identity and literals produce one value.
- Comma concatenates streams and pipe evaluates downstream filters for every upstream value.
- Array and object constructors collect or combine generated values according to jq semantics.
- Field access, indexing, iteration, and slices support arrays, objects, strings, missing values, optional access, and negative indexes.
- Recursive descent emits the input and all descendants in jq order.
- `empty` produces no values.

## Programmatic Acceptance

Intent: The implementation passes the non-empty corpus slice covering core filters and constructors.
Suite: scoped
Requires: executable=python3; scope=test

import os
import subprocess
import sys

select = r"\.|\[|\{|\.\[|\.\w"
result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select", select, "--json"],
    capture_output=True,
    text=True,
    env={**os.environ, "JQ": f"{os.getcwd()}/jq"},

print(result.stdout)
print(result.stderr, file=sys.stderr)
report = json.loads(result.stdout)
summary = report["summary"]
assert sum(summary.values()) > 0
assert summary["fail"] == 0
assert summary["error"] == 0
assert result.returncode == 0

- Preserve stream order, multiplicity, and optional-error behavior.
