# FEATURE: Streaming Builtins

| Field       | Value |
|-------------|-------|
| Version     | 20260821 V1 |
| Description | Provides jq stream serialization, reconstruction, and truncation builtins. |
| Depends On  | ARCHITECTURE.md, FEATURE-Generator-Core.md, FEATURE-Path-Access.md |
| Provides    | tostream, fromstream, truncate_stream |
| Consumes    | ordered filter streams, path expressions |

## Questions

- None.

## Purpose

Implement the streaming representation used by jq for composite values. `tostream` emits path/value stream entries, `fromstream` reconstructs values and containers, and `truncate_stream` removes a specified number of leading path components.

The implementation must preserve stream order, distinguish scalar values from empty-container markers, support nested arrays and objects, and remain compatible with generator backtracking.

## Programmatic Acceptance

=== AC streaming-conformance ===
Intent: The implementation passes the non-empty corpus slice covering tostream, fromstream, and truncate_stream.
Suite: scoped
Requires: executable=python3; scope=test

import json
import os
import subprocess
import sys

selector = r"tostream|fromstream|truncate_stream"
result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select", selector, "--json"],
    capture_output=True,
    text=True,
    env={**os.environ, "JQ": f"{os.getcwd()}/jq"},
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
report = json.loads(result.stdout)
summary = report["summary"]
assert sum(summary.values()) > 0
assert summary["fail"] == 0
assert summary["error"] == 0
assert result.returncode == 0
=== END AC streaming-conformance ===

## Guardrails

## Purpose

Implement the remaining helper builtins defined by the jq manual and `builtin.jq`.
