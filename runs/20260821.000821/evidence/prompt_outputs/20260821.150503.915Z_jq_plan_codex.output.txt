# FEATURE: jq Functions and Lexical Scope

## Programmatic Acceptance

=== AC function-conformance ===
Intent: User-defined functions preserve lexical scope.
Suite: scoped
Requires: executable=python3; scope=test

import subprocess
result = subprocess.run(["./jq", "-c", "def f: 1; f"], input="null\n", capture_output=True, text=True)
assert result.returncode == 0
assert result.stdout.splitlines() == ["1"]
=== END AC function-conformance ===

=== AC recursive-function ===
Intent: Recursive functions evaluate their base case.
Requires: executable=python3; scope=test

import subprocess
result = subprocess.run(["./jq", "-c", "def f: if .==0 then 1 else . * f end; f"], input="0\n", capture_output=True, text=True)
assert result.returncode == 0
assert result.stdout.splitlines() == ["1"]
=== END AC recursive-function ===
