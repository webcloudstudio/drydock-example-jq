<div class="scroll"><table><thead><tr><th>Field</th><th>Value</th></tr></thead><tbody><tr><td>Version</td><td>20260822 V1</td></tr><tr><td>Description</td><td>Provides jq lexical value bindings and variable lookup.</td></tr><tr><td>Depends On</td><td>ARCHITECTURE.md, FEATURE-FLOW-006.md</td></tr><tr><td>Provides</td><td>as bindings, variable lookup, lexical scope, shadowing</td></tr><tr><td>Consumes</td><td>generator evaluator, parser AST</td></tr></tbody></table></div>
<h2>Workflow</h2>
<p>Bindings evaluate the left-hand filter as a generator, bind each produced value lexically, and run the remainder of the expression with the original input and the active binding environment.</p>
<ul><li><code>EXP as $name | REST</code> supports multiple generated bindings.</li><li>Bindings are immutable and lexically scoped.</li><li>Nested bindings may shadow outer names without mutating them.</li><li>Keyword identifiers may be used as binding names.</li><li>Array and object patterns bind missing members as <code>null</code>.</li></ul>
<h2>Programmatic Acceptance</h2>
