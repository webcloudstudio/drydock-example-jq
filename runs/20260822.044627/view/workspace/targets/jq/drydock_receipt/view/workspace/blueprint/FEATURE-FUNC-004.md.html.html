<h2>Purpose</h2>
<p>Support array and object destructuring in <code>as</code> bindings, bind absent members as <code>null</code>, and backtrack through <code>?//</code> alternatives when a pattern or subsequent expression fails.</p>
<h2>Behavior</h2>
<ul><li>Array patterns bind positional elements and use <code>null</code> for missing positions.</li><li>Object patterns bind named fields and nested patterns.</li><li>Alternative patterns try later alternatives when an earlier binding fails.</li><li>Variables introduced by successful alternatives remain available to the following filter.</li><li>Errors from the final alternative propagate as runtime errors.</li></ul>
