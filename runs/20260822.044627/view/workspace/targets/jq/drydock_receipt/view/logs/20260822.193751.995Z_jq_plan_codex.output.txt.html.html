# FEATURE: Core Runtime Errors and Optional Evaluation

| Field       | Value |
|-------------|-------|
| Version     | 20260822 V1 |
| Description | Defines empty streams, runtime errors, optional evaluation, try/catch, and partial output behavior. |
| Depends On  | ARCHITECTURE.md, FEATURE-CORE-002.md |
| Provides    | empty, error, ?, try/catch, partial runtime output |
| Consumes    | ordered generator evaluator |

## Questions

- None.

## Intent

Runtime failures are distinct from compile failures. Filters may suppress errors with `?` or `try`, and values emitted before an uncaught runtime error remain observable.

## Behavior

- `empty` produces no values.
- `error` raises a runtime error.
- `EXP?` suppresses errors from `EXP`.
- `try EXP catch HANDLER` evaluates `HANDLER` with the error value.
- Uncaught runtime errors terminate with exit code 5 after preserving prior output.
