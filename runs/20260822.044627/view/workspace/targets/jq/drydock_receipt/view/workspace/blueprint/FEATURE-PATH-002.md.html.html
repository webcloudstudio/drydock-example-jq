<h2>Purpose</h2>
<p>Implement immutable access and mutation of nested arrays and objects through explicit path arrays.</p>
<h2>Behavior</h2>
<ul><li><code>getpath</code> reads values at supplied paths and returns <code>null</code> for absent paths where specified.</li><li><code>setpath</code> creates missing object and array structure and updates existing values.</li><li><code>delpaths</code> removes all requested paths without mutating the original input.</li><li>Multiple path expressions preserve their generator order.</li><li>Invalid path types, negative indices, and excessive path depth produce jq runtime errors or no-ops according to the specification.</li></ul>
