<div class="scroll"><table><thead><tr><th>Field</th><th>Value</th></tr></thead><tbody><tr><td>Version</td><td>20260822 V1</td></tr><tr><td>Description</td><td>Provides the executable jq command and its basic stdin-to-stdout filter interface.</td></tr><tr><td>Depends On</td><td>ARCHITECTURE.md</td></tr><tr><td>Provides</td><td>./jq -c program execution</td></tr><tr><td>Consumes</td><td>interpreter parser and evaluator</td></tr></tbody></table></div>
<h2>Workflow</h2>
<ol><li>Start the executable at the application root as <code>./jq</code>.</li><li>Accept the exercised <code>-c &#x27;&lt;program&gt;&#x27;</code> interface.</li><li>Read JSON input from standard input.</li><li>Compile and evaluate the jq program for each input value.</li><li>Emit each generated result as one compact JSON line.</li><li>Exit successfully after all inputs complete.</li></ol>
<p>The implementation must support multiple input values and preserve output order. The executable may delegate to modular Python files beside it, but the delivered command remains the root-level executable named <code>jq</code>.</p>
