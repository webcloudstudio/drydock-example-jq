<h2>Purpose</h2>
<p>Implement jq&#x27;s immutable deletion, plain assignment, update assignment, and arithmetic assignment semantics.</p>
<h2>Behavior</h2>
<ul><li><code>del</code> removes values selected by one or more path expressions.</li><li>Plain assignment evaluates the right-hand side against the original input and uses every produced value.</li><li>Update assignment evaluates the right-hand side against each selected value and uses the first result.</li><li>Arithmetic assignments apply the corresponding operator to selected values.</li><li>Defined-or assignment replaces false or null values with the right-hand result.</li><li>Multi-path assignments preserve jq&#x27;s output ordering and multiplicity.</li></ul>
