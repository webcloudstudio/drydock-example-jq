<h2>Workflow</h2>
<p>Reduction and iteration controls consume ordered generator streams and preserve jq&#x27;s state, ordering, Cartesian argument, backtracking, and short-circuit semantics.</p>
<ul><li><code>reduce EXP as $var (INIT; UPDATE)</code> accumulates each generated value.</li><li><code>foreach EXP as $var (INIT; UPDATE; EXTRACT)</code> emits intermediate extracted values.</li><li><code>range</code> supports one, two, and three argument forms.</li><li><code>limit</code>, <code>skip</code>, <code>first</code>, <code>last</code>, and <code>nth</code> operate on generated streams.</li><li>Invalid negative counts for <code>limit</code>, <code>skip</code>, and <code>nth</code> raise runtime errors.</li></ul>
