<article class="doc"><h1>FEATURE: Stream-Valued Filter Evaluation</h1>
<div class="scroll"><table><thead><tr><th>Field</th><th>Value</th></tr></thead><tbody><tr><td>Version</td><td>20260822 V1</td></tr><tr><td>Description</td><td>Evaluate jq filters as ordered streams supporting empty, iteration, and range.</td></tr><tr><td>Depends On</td><td>ARCHITECTURE.md, FEATURE-PARSE-004.md</td></tr><tr><td>Provides</td><td>ordered generator evaluator</td></tr><tr><td>Consumes</td><td>expression AST</td></tr></tbody></table></div>
<h2>Scope</h2>
<p>Implement the evaluator foundation in which every filter consumes one input and yields an ordered stream of zero or more values. Support identity, literals, empty, array and object iteration, recursive stream propagation, range generation, and preservation of output order and multiplicity.</p>
<h2>Programmatic Acceptance</h2>
<p>=== AC core-001-conformance ===<br>Intent: The executable evaluates identity, empty, range, and generator ordering as ordered streams.<br>Suite: scoped<br>Requires: executable=python3; scope=test</p>
<p>import subprocess</p>
<p>def run(program, input_text=&quot;null\n&quot;): return subprocess.run( [&quot;./jq&quot;, &quot;-c&quot;, program], input=input_text, capture_output=True, text=True, )</p>
<p>identity = run(&quot;.&quot;) assert identity.returncode == 0 and identity.stdout == &quot;null\n&quot; assert run(&quot;empty&quot;).returncode == 0 and run(&quot;empty&quot;).stdout == &quot;&quot; assert run(&quot;range(3)&quot;).stdout == &quot;0\n1\n2\n&quot; === END AC core-001-conformance ===</p>
