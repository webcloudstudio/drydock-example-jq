Intent

Implement conversion between jq values and JSON text, plus the required text, HTML, URI, CSV, TSV, shell, and base64 format filters. Preserve interpolation behavior and stream ordering.

Programmatic Acceptance

=== AC text-002-conformance ===
Intent: JSON conversion and output-format filters execute through the candidate executable.

import subprocess

program = '["x"|@text, "x"|@json, "<x>"|@html, "a b"|@uri, "a+b"|@urid, ["a","b"]|@csv, ["a","b"]|@tsv, ["a b"]|@sh, "hi"|@base64, "aGk="|@base64d, ({"x":1}|tojson), ("{\\"x\\":1}"|fromjson)]' result = subprocess.run( ["./jq", "-c", program], input="null\n", capture_output=True, text=True, ) print(result.stdout) print(result.stderr, file=import("sys").stderr) assert result.returncode == 0 values = import("json").loads(result.stdout) assert len(values) == 12 assert values[0] == "x" assert values[1] == '"x"' assert values[2] == "&lt;x&gt;" assert values[3] == "a%20b" assert values[8] == "aGQgYg==" or values[8] == "aGk=" === END AC text-002-conformance ===
