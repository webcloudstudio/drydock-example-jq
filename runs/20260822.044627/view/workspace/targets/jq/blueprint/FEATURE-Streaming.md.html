FEATURE: Streaming Transformations

FieldValue

DescriptionReconstruct, truncate, and emit jq streaming representations.

Providestostream, fromstream, truncate_stream
Consumesordered generator evaluation, input stream controls

Workflow

Streaming filters represent composite JSON values as ordered path/value events. tostream emits the representation, truncate_stream removes a specified number of leading path components, and fromstream reconstructs values from the resulting event stream. Implement these filters with generator ordering, empty-container markers, truncation, and round-trip behavior matching the manual and corpus.
