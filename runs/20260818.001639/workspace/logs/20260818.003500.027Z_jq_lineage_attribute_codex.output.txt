<requirement name="basic-filters-and-values" stories="primitive-filters">
jq supports the same set of datatypes as JSON - numbers,
strings, booleans, arrays, objects (which in JSON-speak are
hashes with only string keys), and "null".
</requirement>

jq never does implicit type conversions.
</requirement>
<requirement name="conditionals-and-boolean-operators" stories="conditionals">

</requirement>

</requirement>
