# FEATURE: Regular-Expression Builtins

| Field       | Value |
|-------------|-------|
| Version     | 20260818 V1 |
| Description | Provides jq regular-expression matching, capture, scanning, splitting, and substitution builtins. |
| Depends On  | FEATURE-String-Builtins.md |
| Provides    | test, match, capture, scan, split, splits, sub, gsub |
| Consumes    | string builtins, generator evaluator |

## Questions

- None.

## Purpose

Implement jq's regular-expression builtins using Python standard-library facilities. Support jq-compatible flags, named and unnamed captures, Unicode codepoint offsets, generator-valued matches, splitting, and replacement interpolation.

## Behavior

- `test`, `match`, and `capture` accept jq string or interpolated regular-expression arguments and optional flags.
- `scan` emits each non-overlapping match, or captured strings when capture groups exist.
- `split` returns an array while `splits` emits a stream.
- `sub` replaces the first matching region; `gsub` replaces all non-overlapping regions.
- Replacement filters may produce multiple strings and may reference named captures.
- Invalid input and invalid expressions raise jq runtime errors with exit status 5 unless caught.

| Consumes    | string builtins, JSON serialization |

## Questions

- None.

## Purpose

Implement jq's format filters and their interpolation behavior with Python standard-library encoders.

## Behavior

- `@text` uses jq string conversion and `@json` emits compact JSON text.
- `@html` escapes the documented HTML/XML characters.
- `@uri` and `@urid` perform URI percent-encoding and decoding.
- `@csv` and `@tsv` serialize arrays using jq's quoting and escaping rules.
- `@sh` emits POSIX-shell-safe arguments.
- `@base64` and `@base64d` implement RFC 4648 conversion.
- Format prefixes followed by string literals preserve literal text while escaping interpolated values.

# FEATURE: Streaming and I/O Builtins

|-------------|-------|
| Version     | 20260818 V1 |
| Description | Provides jq streaming transformations, additional input, environment, diagnostics, and stream-control builtins. |

| Provides    | tostream, fromstream, truncate_stream, input, inputs, debug, stderr, env, $ENV |
| Consumes    | generator evaluator, executable stdin and stderr |

## Questions

- None.

## Purpose

Implement jq's standard-library I/O and streaming behavior while preserving the executable's JSON input stream and diagnostic channels.

## Behavior

- `tostream` emits jq path/value stream records and `fromstream` reconstructs values.
- `truncate_stream` removes the requested path prefix from stream records.
- `input` consumes one subsequent JSON input and `inputs` consumes all remaining inputs.
- `env` and `$ENV` expose the process environment as jq objects.
- `debug` writes diagnostic records to stderr and preserves its input; `stderr` writes raw input to stderr without adding output values.
- I/O builtins preserve ordering and interact correctly with the executable's input cursor.
