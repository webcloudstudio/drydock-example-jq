# FEATURE: Flow Bindings

| Field       | Value |
|-------------|-------|
| Version     | 20260817 V1 |
| Description | Provides lexical variable bindings, destructuring patterns, and destructuring alternatives. |
| Depends On  | FEATURE-Core-Construction.md |
| Provides    | lexical bindings, array patterns, object patterns, destructuring alternatives |
| Consumes    | generator evaluator |

## Questions

- None.

## Scope

Bindings use jq’s lexical generator semantics. `as` evaluates its left filter against the current input, restores the original input for the downstream filter, and binds each produced value independently. Array and object patterns bind missing values as `null`; `?//` tries alternatives with correct variable visibility and backtracking.

# FEATURE: Flow Functions

| Field       | Value |
|-------------|-------|
| Version     | 20260817 V1 |

| Depends On  | FEATURE-Flow-Bindings.md |
| Provides    | def functions, filter arguments, value arguments, arity, closures, recursion |
| Consumes    | lexical bindings |

## Questions

- None.

## Scope

Function definitions are lexically scoped and available only to subsequent expressions, except that a function may refer to itself recursively. Filter parameters receive filters, while `$` parameters receive values. Definitions support multiple parameters, arity overloads, redefinition, closures, and recursive calls.

# FEATURE: Flow Control Errors

| Field       | Value |
|-------------|-------|
| Version     | 20260817 V1 |
| Description | Provides jq conditionals, runtime errors, exception handling, optional filters, labels, breaks, and halting. |

| Provides    | if, then, elif, else, try, catch, optional filters, labels, break |

## Questions

- None.

## Scope

Conditionals use jq truthiness: only `false` and `null` are false. `try` and `catch` transport runtime error values through generator evaluation, while `?` suppresses errors. Labels and `break` provide lexical early termination. `halt` stops successfully; `halt_error` stops with its requested exit code.

# FEATURE: Flow Reduce

| Field       | Value |
|-------------|-------|
| Version     | 20260817 V1 |
| Description | Provides jq reduce and foreach accumulation over ordered generator streams. |
| Depends On  | FEATURE-Flow-Bindings.md, FEATURE-Flow-Control-Errors.md |
| Provides    | reduce and foreach |
| Consumes    | lexical bindings, control flow |

## Questions

- None.

## Scope

`reduce` evaluates its generator once per produced value, applies the update filter to the accumulator, and emits the resulting accumulator stream. `foreach` additionally evaluates an extraction filter after each update. Both preserve generator ordering, support destructuring patterns, multiple initial accumulators, and lexical early termination.
