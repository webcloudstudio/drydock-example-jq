# FEATURE: jq Parser

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Parses jq programs into validated executable filter structures. |
| Depends On  | ARCHITECTURE.md, FEATURE-JQ-Lexer.md |
| Provides    | jq AST parser and compile validation |
| Consumes    | jq tokenization |

## Questions

- None.

## Purpose

The parser consumes lexer tokens and produces an executable jq filter representation. It follows the supplied grammar for precedence, associativity, terms, collections, objects, conditionals, bindings, definitions, reductions, assignments, and module declarations.

Compile-time failures return exit status 3 through the executable boundary. Invalid module metadata, invalid object keys, undefined bindings or labels, malformed delimiters, and invalid syntax must be rejected without filesystem loading.

## Programmatic Acceptance

=== AC parser-conformance ===
Intent: The parser passes the authoritative corpus cases covering grammar, precedence, definitions, bindings, and compile-time rejection.
Suite: scoped

import subprocess
import sys

result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select",
     r"%%FAIL|def |module |include |import | as |\?//|reduce |foreach |if |try |label |break |[{}]"],
    capture_output=True, text=True,
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
assert result.returncode == 0
=== END AC parser-conformance ===

=== AC parser-rejects-invalid-programs ===
Intent: Invalid jq programs are rejected with the declared compile-failure status.

import subprocess

programs = ["{", "}", ". as [] | null", ". as $foo | $bar"]
for program in programs:
    result = subprocess.run(
        ["./jq", "-c", program],
        input="null\n",
        capture_output=True,
        text=True,
    )
    assert result.returncode == 3
=== END AC parser-rejects-invalid-programs ===

=== AC parser-preserves-generator-grammar ===
Intent: Parser output preserves the ordering and multiplicity of representative comma, pipe, collection, and definition expressions.

import json
import subprocess

program = "def f: ., .; [1,2] | .[] | f"
result = subprocess.run(
    ["./jq", "-c", program],
    input="null\n",
    capture_output=True,
    text=True,
)
assert result.returncode == 0
actual = [json.loads(line) for line in result.stdout.splitlines()]
expected = [1, 1, 2, 2]
assert actual == expected
=== END AC parser-preserves-generator-grammar ===

## User Acceptance

- None.

## Guardrails

- Do not invoke a system jq executable or third-party jq implementation.
- Do not load excluded module fixtures while parsing.
- Preserve lexer and parser source assets unchanged.

# FEATURE: jq Strings and Formats

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Implements interpolated strings and jq output-format syntax. |
| Depends On  | ARCHITECTURE.md, FEATURE-JQ-Lexer.md, FEATURE-JQ-Parser.md |
| Provides    | interpolated strings and @format expressions |
| Consumes    | jq AST parser and compile validation |

## Questions

- None.

## Purpose

The interpreter evaluates string literals, escaped text, interpolation expressions, and `@text`, `@json`, `@html`, `@uri`, `@urid`, `@csv`, `@tsv`, `@sh`, `@base64`, and `@base64d` expressions. Interpolations are generator-aware and each produced interpolation value participates in the surrounding string result.

## Programmatic Acceptance

=== AC string-format-conformance ===
Intent: The authoritative corpus passes the interpolation and output-format cases.
Suite: scoped

import subprocess
import sys

result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select",
     r"interpolation|@text|@json|@csv|@tsv|@html|@uri|@urid|@sh|@base64"],
    capture_output=True, text=True,
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
assert result.returncode == 0
=== END AC string-format-conformance ===

=== AC interpolation-produces-values ===
Intent: Interpolation evaluates the input expression and returns the resulting formatted string.

import json
import subprocess

input_value = 42
program = '"value=\(.)"'
result = subprocess.run(
    ["./jq", "-c", program],
    input=json.dumps(input_value) + "\n",
    capture_output=True,
    text=True,
)
assert result.returncode == 0
actual = json.loads(result.stdout)
expected = "value=" + str(input_value)
assert actual == expected
=== END AC interpolation-produces-values ===

=== AC format-round-trip ===
Intent: Base64 encoding and decoding preserve the supplied text.

import json
import subprocess

value = "This is a message"
encoded = subprocess.run(
    ["./jq", "-c", "@base64"],
    input=json.dumps(value) + "\n",
    capture_output=True,
    text=True,
)
assert encoded.returncode == 0
encoded_value = json.loads(encoded.stdout)
decoded = subprocess.run(
    ["./jq", "-c", "@base64d"],
    input=json.dumps(encoded_value) + "\n",
    capture_output=True,
    text=True,
)
assert decoded.returncode == 0
assert json.loads(decoded.stdout) == value
=== END AC format-round-trip ===

## User Acceptance

- None.

## Guardrails

- Preserve JSON escape semantics and Unicode code points.
- Format filters must write produced values to stdout through the normal JSON output path.
- Diagnostics must remain on stderr.

# FEATURE: Generator Core

## Questions

- None.

## Purpose

Every filter evaluation returns an ordered stream. The evaluator preserves zero, one, or many outputs, pipe cartesian behavior, comma concatenation, array collection, object construction, iteration, identity, and `empty` backtracking.

import subprocess

result = subprocess.run(

print(result.stdout)
print(result.stderr, file=sys.stderr)

Intent: A generator pipeline preserves ordered multiplicity across iteration and downstream evaluation.

import json

input_value = [1, 2, 3]

import json
import subprocess

## User Acceptance

- None.

## Guardrails

- Preserve output order, multiplicity, cartesian products, and backtracking.
- Do not collapse filters into single-value functions.
- Values remain immutable from the evaluator's perspective.

# FEATURE: Indexing and Slicing

| Field       | Value |
|-------------|-------|

## Questions

- None.

## Purpose

Index expressions support objects, arrays, strings, dynamic keys, negative indices, iterators, optional access, and slices with omitted or negative bounds. Invalid operations raise jq runtime errors unless the optional operator suppresses them.

## Programmatic Acceptance

=== AC indexing-conformance ===
Intent: The authoritative corpus passes indexing, iteration, optional access, negative-index, and slice cases.
Suite: scoped

import subprocess
import sys

result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select",
     r"\.\w+|\.\[|negative array indices|Slices|\.\\?|\.\[\]\?"],
    capture_output=True, text=True,
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
assert result.returncode == 0
=== END AC indexing-conformance ===

=== AC array-and-string-slices ===
Intent: Array and string slices return the values selected by their supplied bounds.

import json
import subprocess

array_value = [0, 1, 2, 3, 4]
array_result = subprocess.run(
    ["./jq", "-c", ".[1:4]"],
    input=json.dumps(array_value) + "\n",
    capture_output=True,
    text=True,
)
assert array_result.returncode == 0
array_expected = array_value[1:4]
assert json.loads(array_result.stdout) == array_expected

string_value = "abcdef"
string_result = subprocess.run(
    ["./jq", "-c", ".[-3:]"],
    input=json.dumps(string_value) + "\n",
    capture_output=True,
    text=True,
)
assert string_result.returncode == 0
string_expected = string_value[-3:]
assert json.loads(string_result.stdout) == string_expected
=== END AC array-and-string-slices ===

=== AC optional-indexing-errors ===
Intent: Optional indexing suppresses invalid access while ordinary invalid indexing reports a runtime failure.

import json
import subprocess

optional = subprocess.run(
    ["./jq", "-c", ".foo?"],
    input=json.dumps(True) + "\n",
    capture_output=True,
    text=True,
)
assert optional.returncode == 0
assert json.loads(optional.stdout) is None

ordinary = subprocess.run(
    ["./jq", "-c", ".foo"],
    input=json.dumps(True) + "\n",
    capture_output=True,
    text=True,
)
assert ordinary.returncode == 5
=== END AC optional-indexing-errors ===

## User Acceptance

- None.

## Guardrails

- Negative array indices must not silently create elements during reads.
- Optional access suppresses the associated runtime error only.
- Preserve generator output order for dynamic index expressions.

# FEATURE: Operators and Comparisons

| Field       | Value |

- None.

## Purpose

Operators evaluate operands against the same input and preserve generator cartesian products. Arithmetic follows jq type rules; arrays concatenate, strings concatenate or repeat, objects merge, comparisons use jq ordering, boolean operators use jq truthiness, and `//` selects non-null and non-false outputs.

result = subprocess.run(

     r"\+|\-|\*|/|%| == | != | < | > | <= | >= | and | or | //|contains|sort"],
    capture_output=True, text=True,
)
print(result.stdout)
print(result.stderr, file=sys.stderr)

=== AC typed-operator-results ===
Intent: Numeric addition, array concatenation, string concatenation, and object merging follow jq's typed operator behavior.

import json
import subprocess

cases = [
    ("1 + 2", None, 3),
    ("[1] + [2]", None, [1, 2]),
    ('"a" + "b"', None, "ab"),
    ('{"a":1} + {"b":2}', None, {"a": 1, "b": 2}),
]
for program, input_value, expected in cases:
    result = subprocess.run(
        ["./jq", "-c", program],
        input=json.dumps(input_value) + "\n",
        capture_output=True,
        text=True,
    )
    assert result.returncode == 0
    assert json.loads(result.stdout) == expected
=== END AC typed-operator-results ===

=== AC division-by-zero-runtime-error ===
Intent: Division by zero produces the declared runtime-failure status.

import subprocess

    ["./jq", "-c", "1 / 0"],

    capture_output=True,
    text=True,

=== END AC division-by-zero-runtime-error ===

=== AC alternative-truthiness ===
Intent: The alternative operator selects the supplied fallback for false and null values and preserves other values.

import json

    ["./jq", "-c", program],

    text=True,

assert result.returncode == 0

## User Acceptance

- None.

## Guardrails

- Do not coerce incompatible JSON types implicitly.
- Preserve jq's distinction between booleans and numbers.
- Division and remainder by zero must raise runtime errors with exit status 5.
- Preserve operand generator cartesian products and jq ordering rules.
