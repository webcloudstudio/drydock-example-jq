# FEATURE: Numeric Builtins

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Provides jq numeric conversion, mathematical functions, special values, rounding, and numeric capability metadata. |
| Depends On  | ARCHITECTURE.md, FEATURE-Operators-and-Comparisons.md |
| Provides    | numeric conversion, special values, rounding, trigonometric functions, powers, roots, numeric metadata |
| Consumes    | jq operators and comparisons |

## Questions

- None.

## Purpose

Implement the numeric builtin surface described by the jq manual and exercised by the conformance corpus.

## Behavior

Support numeric conversion and boolean conversion, IEEE-style special values, numeric predicates, rounding and truncation, standard one-, two-, and three-argument mathematical functions, powers and roots, and the `have_decnum` and `have_literal_numbers` capability filters. Preserve jq numeric equality, literal handling, and generator behavior.

## Programmatic Acceptance

=== AC numeric-conformance ===
Intent: The numeric builtin implementation passes its authoritative conformance slice.
Suite: scoped
Requires: executable=python3; scope=test

import subprocess
import sys

selector = "tonumber|toboolean|infinite|nan|isfinite|isnan|isinfinite|isnormal|floor|sqrt|pow|sin|cos|round|have_decnum|have_literal_numbers"
result = subprocess.run(
    [sys.executable, "sources/run_conformance.py", "--select", selector],
    capture_output=True,
    text=True,
)
print(result.stdout)
print(result.stderr, file=sys.stderr)
assert result.returncode == 0
=== END AC numeric-conformance ===

=== AC numeric-cli-contract ===
Intent: Numeric filters execute through the declared jq executable contract.
import json
import subprocess

source = "1\n"
program = "[., . + 1, floor, sqrt]"
result = subprocess.run(["./jq", "-c", program], input=source, capture_output=True, text=True)
assert result.returncode == 0
values = [json.loads(line) for line in result.stdout.splitlines()]
assert len(values) == 1
assert values[0][0] == json.loads(source)
assert values[0][1] == values[0][0] + 1
=== END AC numeric-cli-contract ===

=== AC numeric-error-contract ===
Intent: Invalid numeric conversion produces the runtime failure status.
import subprocess

result = subprocess.run(
    ["./jq", "-c", "tonumber"],
    input='"not-a-number"\n',
    capture_output=True,
    text=True,
)
assert result.returncode == 5
=== END AC numeric-error-contract ===

## User Acceptance

- None.

## Guardrails

- Use only Python standard-library numeric facilities.
- Do not shell out to jq or use a third-party jq implementation.

=== AC inputs-order ===
Intent: The inputs builtin preserves the order and multiplicity of remaining JSON inputs.
import json
import subprocess

payload = "1\n2\n3\n"

    ["./jq", "-c", "inputs"],
    input=payload,
    capture_output=True,
    text=True,

    ["./jq", "-c", "debug"],

assert result.stderr != ""

- None.

## Guardrails

- Diagnostics go to stderr; produced JSON values go to stdout.
- Do not access the network or require external services.

# FEATURE: Modules

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Provides jq module grammar validation and preserves the declared unsupported loader exclusions. |
| Depends On  | ARCHITECTURE.md, FEATURE-JQ-Parser.md, FEATURE-Builtin-Library.md |
| Provides    | module, import, include grammar and loader exclusions |
| Consumes    | jq AST parser and compile validation |

## Questions

- None.

## Purpose

Implement module, import, and include syntax sufficiently to validate supported grammar and reject invalid module forms without attempting unsupported filesystem loading.

## Behavior

Accept valid module declarations where supported by the interpreter. Reject non-constant or non-object module metadata, non-constant import paths and metadata, invalid escapes, and malformed module syntax with compile exit status 3. Preserve the supplied loader cases in `sources/exclusions.txt`; do not broaden exclusions or load external module fixtures.
