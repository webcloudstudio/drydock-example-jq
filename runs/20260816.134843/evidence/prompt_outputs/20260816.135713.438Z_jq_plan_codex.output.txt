# FEATURE: Builtin Metadata

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Expose builtin discovery and interpreter capability metadata. |
| Depends On  | FEATURE-Builtin-Library.md, FEATURE-Modules.md |
| Provides    | builtins, have_decnum, have_literal_numbers, modulemeta |
| Consumes    | builtin jq function library, module metadata |

## Questions

- None.

## Purpose

Provide the metadata surface required by jq 1.8.2, including builtin enumeration, numeric capability flags, and module metadata.

## Behavior

- `builtins` returns available builtin names with arities.
- `have_decnum` reports the selected numeric backend capability.
- `have_literal_numbers` reports literal-number preservation support.
- `modulemeta` exposes module metadata, dependencies, and definitions.
- Metadata queries preserve jq generator and error semantics.

## Programmatic Acceptance

=== AC builtin-metadata ===
Intent: The interpreter exposes builtin discovery and numeric capability filters.

import json
import subprocess

program = "[builtins|type, have_decnum|type, have_literal_numbers|type]"
result = subprocess.run(
    ["./jq", "-c", program],
    input="null\n",
    capture_output=True,
    text=True,
)
assert result.returncode == 0
values = [json.loads(line) for line in result.stdout.splitlines()]
assert values
assert values[0] == ["array", "boolean", "boolean"]
=== END AC builtin-metadata ===

=== AC modulemeta-query ===
Intent: The module metadata builtin accepts a module name and returns a metadata object.

import json
import subprocess

program = "modulemeta | type"
result = subprocess.run(
    ["./jq", "-c", program],
    input='"c"\n',
    capture_output=True,
    text=True,
)
assert result.returncode in (0, 5)
if result.returncode == 0:
    assert [json.loads(line) for line in result.stdout.splitlines()] == ["object"]
=== END AC modulemeta-query ===

=== AC metadata-conformance ===
Intent: The authoritative corpus cases for builtin metadata pass.

import os
import subprocess

result = subprocess.run(
    ["python3", "sources/run_conformance.py", "--select", "builtins|length|have_decnum|have_literal_numbers|modulemeta"],
    env={**os.environ, "JQ": "./jq"},
    capture_output=True,
    text=True,
)
print(result.stdout)
print(result.stderr)
assert result.returncode == 0
=== END AC metadata-conformance ===

## User Acceptance

- None.

## Guardrails

- Do not report unsupported numeric capabilities as available.
- Do not implement module metadata by loading excluded fixture files.
- Do not shell out to a system jq implementation.

# FEATURE: Interpreter README

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Document the standalone jq interpreter contract and verification command. |
| Depends On  | FEATURE-Command-Line-Errors.md, FEATURE-Command-Line-IO.md, FEATURE-Full-Conformance.md |
| Provides    | README.md interpreter contract documentation |
| Consumes    | ./jq -c program execution |

## Questions

- None.

## Purpose

Document how developers invoke the executable, interpret its output, and run conformance verification.

## Documentation Contract

`README.md` must state:

- The executable is `./jq`.
- Programs are supplied through `-c '<program>'`.
- JSON values are read from standard input.
- Compact JSON outputs are written one per line to standard output.
- Exit code `0` means success, `3` means compile failure, and `5` means runtime failure.
- Diagnostics are written to standard error.
- No installation or network access is required.
- Full verification is run with `sh sources/full_test.sh`.

## Programmatic Acceptance

=== AC readme-contract ===
Intent: README documents the executable invocation, exit codes, and full verification command.

from pathlib import Path

    "-c",
    "stdin",
    "stdout",
    "3",
    "5",
    "stderr",
    "sh sources/full_test.sh",
]
for token in required:
    assert token in readme
=== END AC readme-contract ===
