# FEATURE: Ordering and Containment

| Field       | Value |
|-------------|-------|
| Version     | 20260816 V1 |
| Description | Provides jq ordering, grouping, uniqueness, extrema, containment, and binary-search builtins. |
| Depends On  | FEATURE-Operators-and-Comparisons.md, FEATURE-Structural-Builtins.md |
| Provides    | sort, sort_by, group_by, unique, unique_by, min, max, min_by, max_by, contains, inside, bsearch |
| Consumes    | ordered filter streams, jq comparison semantics |

## Questions

- None.

## Purpose

This feature implements structural ordering and collection analysis over jq values. It preserves jq's ordering hierarchy, lexical comparison rules, stable grouping behavior, duplicate elimination, extrema selection, containment semantics, and binary-search insertion results.

## Behavior

- `sort` and derived functions accept arrays and use jq ordering across nulls, booleans, numbers, strings, arrays, and objects.
- `sort_by`, `group_by`, `unique_by`, `min_by`, and `max_by` evaluate filter arguments with generator semantics.
- `contains` and `inside` recurse through strings, arrays, and objects.
- `bsearch` returns an existing index or the negative insertion-point encoding.

## Questions

- None.

## Purpose

This feature implements jq's generator and reduction utilities. Every operation must preserve ordered streams, cartesian evaluation of filter arguments, backtracking, short-circuiting, and control-flow termination.

- Reduction and iteration helpers preserve multiple initial values and intermediate outputs.
