## Workflow

1. Start the executable at the application root.
2. Accept `-c` followed by one jq program.
3. Read JSON input from stdin.
4. Evaluate the program for each input value.
5. Emit every produced value as compact JSON on its own stdout line.
6. Return the interpreter's documented status.

The command must run directly from the application directory without installation or network access.

## Interface

```text
./jq -c '<program>'
stdin: JSON values
stdout: one compact JSON value per produced result, per line
```
