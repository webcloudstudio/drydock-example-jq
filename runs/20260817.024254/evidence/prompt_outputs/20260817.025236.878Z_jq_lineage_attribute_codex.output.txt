<requirement name="preserve-upstream-corpus" stories="verify-001">
The corpus in sources/jq.test is byte-for-byte upstream and is never edited.
</requirement>
<requirement name="audit-exclusion-entries" stories="verify-002">
This file is a scoring asset: it is hash-verified against the import and restored before grading.
</requirement>
<requirement name="reject-unmatched-exclusions" stories="cli-002">
An entry that matches no case in the corpus is a hard error (exit 2), not a shrug — a silent no-op would quietly re-admit a case the kit cannot run if the corpus pin ever moved.
</requirement>
<requirement name="exclude-module-loader-cases" stories="verify-003">
Only the loader cases are excluded.
</requirement>
<requirement name="retain-module-grammar-cases" stories="frontend-001,frontend-002">
The module *grammar* cases — `module (.+1); 0`, `module []; 0`, `include "a" (.+1); 0`, `include "a" []; 0`, `include "\ "; 0`, `include "\(a)"; 0`, and `%::wat` — remain in the scored set: they are parse errors that a correct front end rejects without ever touching the filesystem.
</requirement>
